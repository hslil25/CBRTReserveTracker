# CBRT FX Reserves

🔗 **Live site:** https://hslil25.github.io/CBRTReserveTracker/

Live tracker for Central Bank of Türkiye FX reserves, sourced from EVDS.

## Setup

```bash
npm install
cp .env.example .env.local   # paste your EVDS API key
npm run dev
```

Get an API key at https://evds3.tcmb.gov.tr/
